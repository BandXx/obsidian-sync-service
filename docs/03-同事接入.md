# 给同事：LiveSync 设置改成"无限制"

目标：把同步的限制全部拆掉，让这个库当仓库用，什么文件都传、什么都不跳过。

做完两边设置要**完全一致**，否则会出现"服务器拒绝同步"或文件重复。

---

## 第 0 步：先打开「高级模式」

`设置` → `第三方插件` → **Self-hosted LiveSync** → 上方搜索框输入 `高级`

找到 **`启用高级模式`**（Use Advanced Mode），打开。

不打开这一步，下面大部分选项在界面上看不到。

---

## 第 1 步：改这 7 项

设置页顶部有搜索框，逐项搜、逐项改。

| # | 搜索词 | 项目 | 改成 |
|---|---|---|---|
| 1 | `最大文件大小` | Max file size | **`102400`**（单位 MB） |
| 2 | `不匹配` | 处理大小不匹配的文件 | **开** |
| 3 | `隐藏文件同步` | 同步 `.obsidian` 内部文件 | **开** |
| 4 | `忽略文件` | Ignore files | **清空** |
| 5 | `忽略模式` | Ignore patterns | **清空** |
| 6 | `用于匹配同步文件的模式` | syncOnlyRegEx | **清空** |
| 7 | `冲突` → `冲突与删除选项` | 冲突时应用最新更改 | **开** |

### 关于第 1 项

原来默认 50MB，超过就静默跳过——视频、大 PDF、设计源文件全丢。改成 102400 MB 等于取消限制。

### 关于第 2 项

关着的时候，同步过程中被改动过的文件会被直接跳过、不重试。这是"文件莫名其妙少了一部分"最常见的原因。

---

## 第 2 步：排除名单（重要）

搜索 `忽略模式`，找到 **`忽略模式`** 下面那个长条输入框
（英文 `Ignore patterns`，在「隐藏文件」那一组里，不是前面第 5 步那个全局忽略模式）

**整段替换成：**

```
\/obsidian-livesync\/
```

只剩这一项。

| 排除项 | 加它的原因 |
|---|---|
| `\/obsidian-livesync\/` | 这个目录里存的是各自的服务器密码。同步会互相覆盖，直接断连 |

**注意：`.git`、`workspace.json`、`community-plugins.json`、`app.json`、`appearance.json` 全都不排除了。**
它们的后果是：两边窗口布局会互相跳、插件启用列表会互相同步。这是"全都打开"的代价，接受就接受，不接受就自己加回排除。

---

## 第 3 步：绝对不要动的一项

**`大小写敏感性`（Handle filename case sensitive）必须保持「关」。**

这一项**不能开**。原因是这样：

LiveSync 存在服务器上的每篇笔记，文件名不是明文，而是一串哈希（指纹）。这串指纹是用**文件路径**算出来的。大小写敏感性这个开关会改变算哈希前的处理方式：

- 关：路径先全部转小写再算
- 开：保留原样算

所以一旦开启，`DanKoe/`、`Obsidian-部署记录.md` 这类带大写字母的路径，算出来的指纹跟服务器上已有的完全对不上。插件会认为"这个库是别的程序建的"，直接拒绝整场同步，报：

```
The remote document IDs do not match the configured ID key.
```

这个错误我已经实际撞到过一次，回退这一项之后立刻恢复。

**结论：这一项保持关闭，两边都不用管它。**

代价：`Note.md` 和 `note.md` 会被当成同一个文件。macOS 的文件系统本来也不区分大小写，日常碰不到。

---

## 第 4 步：重启 + 同步

1. 完全退出 Obsidian（`Cmd + Q`），重新打开
2. `Cmd + P` → `LiveSync: Sync now` → 回车
3. 等 3-10 分钟。内部文件（`.obsidian`）第一次要过一遍，比平时慢

---

## 第 5 步：验证

`Cmd + P` → `LiveSync: Show log`，看最后几行。

**正常的样子**：

```
Replication activated
Sync: 💤  ↑ 26 ↓ 4
```

**异常的样子**（出现任意一条就是没配对）：

| 日志里出现 | 说明 |
|---|---|
| `The remote document IDs do not match the configured ID key` | 大小写敏感性被开了，关回去 |
| `远程数据库较新或已损坏` | 同上，或加密口令不一致 |
| `无法连接到服务器` | 地址／账号／密码不对 |
| `too large` / `size mismatched` | 第 1、2 项没改到 |

---

## 最终对照表（两边都要一样）

| 设置 | 值 |
|---|---|
| 高级模式 | 开 |
| 最大文件大小 | 102400 |
| 处理大小不匹配的文件 | 开 |
| 隐藏文件同步 | 开 |
| 忽略文件 | 空 |
| 忽略模式 | 空 |
| 仅同步模式 | 空 |
| 隐藏文件忽略名单 | `\/obsidian-livesync\/` |
| 冲突时应用最新更改 | 开 |
| **大小写敏感性** | **关（不要动）** |
| 加密 / 路径混淆 / 内部元数据加密 | 不动，保持原状 |

---

## 已知的硬限制

服务器磁盘 **40G，已用 18G，剩 20G**。这是云服务器硬盘，不是软件设置，改不了。视频和大压缩包会实打实吃这个量。
